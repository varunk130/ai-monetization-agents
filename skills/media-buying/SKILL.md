# Media buying

1. Ask each ad platform's agent for a quote at an equal share of the weekly budget: business type, city, weekly budget. Never share the business's revenue or margins.
2. Compare expected customers and cost per customer.
3. Set the launch split with the planning tool, which accounts for diminishing returns.
4. Return the weekly split and one line per platform on why.
