# Weekly optimization

Each week:
1. Run the week with the current split.
2. Read cost per customer by channel. One week is noisy: move budget gradually, never all of it.
3. Replan with the updated beliefs.

After the last week, compare total customers to an even split over the same weeks, and say which channels beat or missed their benchmarks.
